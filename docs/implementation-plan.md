# 实施计划与验收标准

| 阶段 | 工作 | 验收标准 |
| --- | --- | --- |
| P0 权限与设备确认 | 确认手机型号、已购设备、官方允许的操作 | 记录许可及设备规格；不明确则停止对应采集 |
| P0 音频短测 | 使用自有或获准录制的 1–2 分钟样本 | WAV 可打开、时长符合样本、无明显底噪、削波或中断 |
| P0 音频长测 | 一个完整的获准课时或自有样本 | 文件完整、无明显丢失，记录存储与供电状况 |
| P1 视频可行性 | 确认手机正常输出能力、系统和采集设备兼容性 | 自有样本正常显示；对保护或禁止采集的内容停止，不强制成功 |
| P1 视频短测/长测 | 对明确允许的信号测试画面及声音 | 文件可播放、清晰、音画同步、时长完整 |
| P2 归档规划 | 仅处理录制已完成的文件 | 文件命名、完整性检查、失败记录；未实现代码 |

交付物为标准本地媒体文件及测试记录。可选择任意下游转写工具，不依赖其他仓库。不得提交课程、授权码、个人信息和未获准公开的衍生内容。

当前全部硬件验收项未实测。以 tests 下的模板记录结果，不虚报通过。
